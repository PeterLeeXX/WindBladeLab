# 边界
本模块实现已批准的根目录 `plan.md` 所定义的论文离线全局规划部分，不实现 VT-NMPC 控制器。运行依赖仅 NumPy；输入仅支持本模块生成且保留物理叶片身份的三长方体网格。不承诺真实翼型、任意网格、安全转场或可飞行轨迹。

# 几何契约
世界 z 向上，局部轴 x，转子在 yz 平面；轮毂在塔基上方 tower_height。yaw 绕世界 z，rotor_angle 绕局部 x，均为右手规则。零转子角的物理叶片 0 向上。厚度为宽度的三分之一。

由三角形外向法向与重心平面在每片叶片内分组，排除端盖。稳定表面 ID 为 `(blade, side)`，blade 为 0–2，side 为 0–3，依次对应负切向、正轴向、正切向、负轴向；旋转不改变 ID。重心以 z 排序，水平退化以叶片纵向位置破平局。纵向条带内先平均成对三角形重心，避免对角线引入人为拟合斜率；以纵向位置拟合并延伸至物理根尖截面。单条带欠定时使用已知叶片纵轴。

# 排序与参考契约
对每个选中表面连续访问其两个端点，各面恰好一次。开放路线自由起终点，以面内距离及面间连接欧氏距离总和为目标，不附加法向偏移、禁边或转弯代价。局部缓存精确枚举全部顺序和方向，严格代价比较，同值依稳定 ID 及方向（根至尖优先）决定；缓存不跨求解。

Plan 只含 points、normals、surface_order、offsets、distance。每个半开 offsets 区间仅采样一个面，含两端点，使用 ceil(长度/spacing) 个间隔及该面的同一外向三维单位法向。跨面不插值、不混合法向、不去重。distance 是端点图代价，不是飞行距离。segments 与 spacing 独立。

# 两阶段契约
便捷入口仅接受叶片 0 向上的倒 Y（整圈等价及方向数值容差内误差）。初始外向法向世界 z 分量低于负方向容差的两面留至第二阶段，其余十面先规划。绕轮毂正转 120° 后重新生成几何，对这两个物理侧面单独精确求解；两个 Plan 不构成含转场/旋转代价的整任务最优。

# 验证边界
无效参数与异常几何使用 ValueError。最优性以独立小规模全排列为基准，几何/采样/两阶段以不变量及论文 50/3/120 m 尺寸验收。性能仅实测记录，不设硬件相关阈值；数值运算基于 float64，不声称符号精确或真实图像覆盖率。
